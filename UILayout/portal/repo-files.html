ashfall-game

The Unreal project for Ashfall: maps, blueprints, C++ code and config. Art sources live in ashfall-art.

Layout

  • Content/: maps, blueprints and imported assets. Binary files here need a lock.
  • Source/: C++ game code, reviewed through merge requests.
  • Config/ and Plugins/: project settings and engine plugins.

Locks

Lock a binary file before you edit it, for example lore lock Content/Maps/Frostreach/Frostreach_P.umap, and release it when you push. Locks held longer than 14 d are marked stale.

Getting started

Clone with lore clone lore://lore.emberline.gg/ashfall-game, then open Ashfall.uproject.
